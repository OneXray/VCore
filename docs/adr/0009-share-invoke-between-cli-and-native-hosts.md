# ADR 0009：CLI 与原生宿主共用 Invoke

CLI 和原生传输都调用同一 Invoke 请求处理器，让配置准入、实例表、平台资源获取与停止屏障具有一份实现。公开业务启动合并为 `start(configYaml)`，配置准备保留在命令内部；TUN 的设备和借用描述符来自 YAML，包格式由平台内部选择。

前台进程需要文件与标准输入、环境和路径默认值、退出信号及完整清理，因此这些行为归属显式的 `foreground` 操作；CLI 只处理五个参数、请求转换、输出和退出码。普通业务生命周期不接管宿主信号或角色，使 VPN、服务和嵌入式宿主继续管理自己的进程生命周期。原生路径作为字符串或平台编码元数据无损传递，不通过有损文本转换。

前台与业务调用共用单实例约束。前台等待信号或引擎完成时释放命令锁，结束时 join 启动/引擎工作并停止、销毁实例；观察到完成不代替真实清理屏障。当前请求及文件行为见 [Invoke API](../invoke-api.md)与 [CLI](../cli.md)。

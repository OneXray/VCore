## Required 集合

| ID | 必需证据 |
| --- | --- |
| N10-BUILD-APPLE | 同候选 Release：iOS arm64、simulator arm64/x86_64、macOS arm64/x86_64；XCFramework、实际架构和最终原生 C 链接 |
| N10-BUILD-ANDROID | 同候选 Release：arm64-v8a/x86_64 libvcore.so 和匹配 libc++_shared.so；ELF 架构、NDK/API |
| N10-BUILD-WINDOWS-ARM64 | 原生 ARM64 Windows/MSVC；DLL/Provider/Session 三件套、包集成 revision3、原生 C 加载 |
| N10-BUILD-WINDOWS-X64 | 原生 x64 Windows/MSVC；同样三件套、包集成 revision3、原生 C 加载 |
| N10-DEVICE-IOS | 物理 iOS 完整宿主、真实双栈/DNS/数据面和生命周期 |
| N10-DEVICE-ANDROID | 物理 Android 完整宿主、protect、真实双栈/DNS/数据面和生命周期 |
| N10-DEVICE-MACOS | 物理 macOS 正式平台集成、真实双栈/DNS/数据面和生命周期 |
| N10-DEVICE-WINDOWS | 物理 Windows 平台集成、物理出口绑定、真实双栈/DNS/数据面和生命周期 |
| N10-CI | 最终候选 commit 上实际运行、通过的四组生产 CI；URL、原始产物、保留期限 |
| N10-INSTALL-IOS | 正式签名宿主安装、更新、卸载，绑定同候选库和宿主身份 |
| N10-INSTALL-ANDROID | 正式签名宿主安装、更新、卸载，绑定同候选库和宿主身份 |
| N10-INSTALL-MACOS | 正式签名宿主及平台 extension 安装、更新、卸载 |
| N10-INSTALL-WINDOWS | 正式签名 MSIX 安装、更新、卸载；原生 x64/ARM64、Windows10/11、WACK/Store 既有门禁 |

四个 DEVICE 项均必须验证 Trojan、VMess、VLESS、Hysteria2，并回归
SOCKS5/AnyTLS/SS2022；覆盖 TCP/UDP、真实 DNS/IPv4/IPv6、平台防递归、
断网/换网、前后台、至少20次连接/停止、HY2跳端口及同步清理。
模拟器、C ABI、容器 IPv6、合成 TUN、历史宿主测试不抵扣这些项目。
所有协议服务端/原站仍须隔离；不自动开放宿主端口或改动工作机 VPN/路由/DNS。

日志/CI来源。CI 下载后重新校验文件，不能只读取作业绿色状态。

仅 Cargo 源码摘要。每次新候选需重新生成；不混用不同源码/lock 的平台产物。
既有 Windows 包集成 JSON 不修改；新记录包围该原有交付接口。

- 可使用本机 Apple/Android 构建工具链和公开仓库 CI。
- 本次只检测到 iOS 模拟器、Android 模拟器，没有连接的物理手机。
- 本次未发现运行中的 Windows VM；另一虚拟机管理 CLI 超时，未据此认定
  所有离线虚拟机都不存在。原生 Windows 构建转由对应架构 CI 验证。
- 尚未绑定本候选的正式宿主、签名安装记录、Windows10/11设备与Store证据。
  私有宿主身份/路径/配置不进入本仓库或公开 CI。

因此 N10.2/N10.4 仍为 NOT RUN，需要独立设施与真实证据。没有执行商店提交、
更改系统 VPN/路由/DNS、启动宿主协议服务端，或把旧记录改记为本候选通过。

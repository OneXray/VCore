Mihomo listener 是默认对端；仅其缺少的 HTTP 首包、legacy H2、自定义头/路径 WS ED 使用官方 V2Ray。TCP 每方向 10 MiB，覆盖 IPv4/IPv6/域名及服务器先发；UDP 每编码/目标类型按五档大小各 100 包，实际对端容量与生产协议上限分开记录，另验预算 +1 拒绝、来源/关联隔离与取消。

这同时补齐 N0-F 中本阶段实际使用的 V2Ray HTTP/H2/扩展 WS ED 与 raw/XUDP/packetaddr 解码证据；显式 raw 只证明自身路径，不替代默认 XUDP。该结论不推广到 N5/N7 高级封装、下载/复用的所有组合，也不将完整 N0-F 改为 PASS。

关闭检查中 **18 组为同组合官方 Mihomo 客户端差分，WS + REALITY 另有 3 组分层参照（普通 WS、HTTPUpgrade、fast-open）**：
